# Feature Specification: Kotlin 콘솔 지뢰찾기 (Minesweeper)

## Overview
콘솔 기반 지뢰찾기 게임을 Kotlin으로 구현한다. 사용자는 텍스트 명령으로 셀을 열거나 깃발을 놓아 지뢰를 피하며 모든 안전 셀을 열면 승리한다.

## User Scenarios & Testing

### User Story 1: 게임 플레이
- As: 사용자는
- I: 콘솔에서 지뢰찾기 게임을 플레이할 수 있다
- So: 간단한 텍스트 기반 게임을 즐기기 위해

#### Acceptance Scenarios

Scenario 1: **보드 생성 및 표시**
- Given: 게임이 시작될 때
- When: 9x9 보드가 생성되면
- Then: 10개의 지뢰가 무작위로 배치되고, 모든 셀이 숨김 상태로 표시된다

Scenario 2: **셀 열기**
- Given: 게임이 진행 중일 때
- When: 사용자가 좌표를 입력하면
- Then: 해당 셀이 열리고 인접 지뢰 수가 표시된다

Scenario 3: **재귀적 열기**
- Given: 인접 지뢰가 0인 셀을 열었을 때
- When: 해당 셀이 열리면
- Then: 인접한 빈 셀들이 자동으로 열린다

Scenario 4: **깃발 표시**
- Given: 게임이 진행 중일 때
- When: 사용자가 깃발 명령을 입력하면
- Then: 해당 셀에 깃발이 토글되고, 깃발이 있는 셀은 열 수 없다

Scenario 5: **승리 조건**
- Given: 지뢰가 아닌 모든 셀이 열렸을 때
- When: 마지막 안전 셀이 열리면
- Then: "승리" 메시지가 표시되고 게임이 종료된다

Scenario 6: **패배 조건**
- Given: 게임이 진행 중일 때
- When: 지뢰가 있는 셀을 열면
- Then: 모든 지뢰 위치가 공개되고 "패배" 메시지가 표시된다

Scenario 7: **첫 클릭 안전**
- Given: 게임 시작 후 첫 번째 셀을 열 때
- When: 해당 위치에 지뢰가 있더라도
- Then: 지뢰가 다른 위치로 재배치되어 첫 클릭은 항상 안전하다

## Functional Requirements
- FR-1: MUST 9x9 크기의 보드를 생성하고 10개의 지뢰를 무작위로 배치한다
- FR-2: MUST 사용자가 좌표(행, 열)를 입력하여 셀을 열 수 있다. 열린 셀은 인접 지뢰 수를 표시한다
- FR-3: MUST 인접 지뢰 수가 0인 셀을 열면, 주변 8방향의 셀을 재귀적으로 자동 열기한다
- FR-4: MUST 사용자는 깃발(Flag)을 놓아 지뢰 의심 셀을 표시할 수 있다. 깃발이 있는 셀은 열 수 없다
- FR-5: MUST 지뢰가 아닌 모든 셀을 열면 승리, 지뢰 셀을 열면 패배로 판정한다
- FR-6: MUST 첫 번째 셀 열기 시 해당 위치에 지뢰가 있으면 지뢰를 다른 빈 위치로 재배치한다

## Constraints
- CON-1: MUST Kotlin 언어만 사용한다 (빌드 도구 없이 .kt 파일로 구성)
- CON-2: MUST 콘솔(CLI) 기반으로 동작한다
- CON-3: MUST 외부 라이브러리 없이 Kotlin 표준 라이브러리만 사용한다

## Success Criteria
- SC-1: 게임을 시작하면 9x9 보드가 표시된다
- SC-2: 셀 열기, 재귀적 열기, 깃발 표시, 승패 판정이 모두 정상 동작한다
- SC-3: 첫 클릭은 항상 안전하다
- SC-4: 모든 기능이 콘솔에서 텍스트 명령으로 조작 가능하다
